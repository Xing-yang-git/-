## 一、注册与登录

> **核心校验规则速查**（来自前后端代码）：
>
> - 手机号唯一性范围：**小区级**（同一手机号可在不同小区分别注册）
> - 房间+身份唯一性：同一房间同一身份（业主/租客）只能注册一个用户
> - 同一房间不同身份（一个业主 + 一个租客）允许共存
> - 密码：8-20 位，必须同时包含字母和数字（前后端双重校验）
> - 楼栋号 1-99、单元号 1-9、房号 1-9999
> - 用户身份映射：`owner` → 业主，`tenant` → 租客
>
> **API 已验记录（2026-07-27）**：以下后端逻辑已通过 curl 直接验证，无需再手动测试：
> `手机号+小区唯一性` `房间+身份唯一性` `密码后端校验` `登录凭据校验` `跨小区登录隔离` `token 版本递增`。
> 已验 case 已从文档中移除，仅保留需在小程序端手动操作的 UI/流程类测试。

### 1.1 注册——基础流程

#### TC-REG-01：正常注册全流程（从登录页入口）

- **前置条件**：未注册手机号，已安装小程序
- **操作步骤**：
  1. 打开小程序 → 进入登录页
  2. 点击"注册"按钮 → 进入注册页
  3. Step 1：搜索/选择小区 → 点击下一步
  4. Step 2：输入栋号（如 `3`）、单元号（如 `2`）、房号（如 `1501`），选择"业主" → 点击下一步
  5. Step 3：输入手机号 `13800000001` → 密码 `pass1234` → 确认密码 `pass1234` → 真实姓名 `张三` → 点击下一步
  6. Step 4：上传至少 1 张证件照片 → 点击提交
  7. 提交成功 → 跳转至审核状态页
- **预期结果**：每步校验通过无阻断；提交后显示 toast "提交成功，请等待物业审核"；约 1.2 秒后跳转到 review-status 页，显示 authStatus = `PENDING`
- **实际结果**：与预期结果一致
- **Bug 备注**：无

- **前置条件**：未注册手机号
